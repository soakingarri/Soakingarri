# Soakingarri AI
AI built by Africans for Africans. 
Meme Generator Tab

The files are 3 distinct python programs that make the Meme generator functional. A meme generator that takes in pictures, video and texts input to to generate Memes. A video and picture extractor program to extract photos and videos from youtube links. And an image-idea suggestor program to generate photo and video ideas to create memes within a certain context.
